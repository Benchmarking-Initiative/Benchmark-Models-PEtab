A collection of mathematical models with experimental data in the [PEtab](https://github.com/PEtab-dev) format as benchmark problems in order to evaluate new and existing methodologies for data-based modelling. The publication for the introduction and analysis of the benchmark problem collection is available at https://academic.oup.com/bioinformatics/article/35/17/3073/5280731.

Contributions to the collection are very welcome. Please see [CONTRIBUTING.md](CONTRIBUTING.md) for more details.

## Overview

The collection spans a wide variety of problems, in terms of application
as well as the numbers of observables, parameters, measurements, and
experimental conditions, and features such as events, preequilibration,
and noise and prior distributions.
For these details, see the sortable and filterable
[overview tables](https://benchmarking-initiative.github.io/Benchmark-Models-PEtab/).

The following table lists the problems in the collection and the
available encodings in PEtab v1 and v2.
The PEtab files are available in the respective subdirectories.
